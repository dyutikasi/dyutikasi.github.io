# Dyuti Kasi - Portfolio Website

A modern, responsive portfolio website showcasing academic achievements, leadership experiences, and community service.

## Features

- 🎨 Modern design with gradient color scheme
- 🌓 Dark/Light theme toggle
- 📱 Fully responsive (mobile, tablet, desktop)
- ✨ Smooth animations and transitions
- 🎯 Clean, professional layout

## Sections

- **Home** - Introduction and hero section
- **About** - Personal information and statistics
- **Achievements** - Awards and recognitions
- **Projects** - Featured projects and work
- **Contact** - Get in touch form and social links

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- No frameworks or libraries required

## Local Development

Simply open `index.html` in your web browser to view the portfolio locally.

## Customization

To personalize your portfolio:

1. **Personal Information** - Update your name, subtitle, and description in `index.html`
2. **Statistics** - Modify GPA, AP courses, and service hours in the About section
3. **Achievements** - Add/edit your awards and accomplishments
4. **Projects** - Update project descriptions and images
5. **Contact Info** - Add your email, social media links, and location
6. **Images** - Replace placeholder images in the `images/` folder
7. **Colors** - Customize color scheme in `css/styles.css` (CSS variables at the top)

## Deployment

This portfolio is deployed on GitHub Pages at: `https://dyutikasi.github.io/portfolio-website/`
